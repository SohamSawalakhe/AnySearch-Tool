# 🔍 AnySearch Tool

**AnySearch Tool** is a feature-rich desktop file search and management application built using Python and Tkinter. It provides a seamless and powerful way to search, preview, organize, and manage your local files with a modern interface.

---

## ✨ Features

- **Advanced File Search**: Instantly search for files across all drives or a specified directory.
- **File Type Filters**: Filter by PDFs, Videos, Audio, Photos, Word, Excel, or view everything.
- **File Operations**:
  - Open files directly from the interface
  - Delete, Rename, Copy, or Move selected files
  - Create new folders
  - Compress multiple files into a ZIP archive
- **Text Preview**: View contents of `.txt` files within the app.
- **Bookmarks**: Bookmark files for quick access later.
- **QR Code Generation**: Create a QR code linking to any file on your system.
- **Share via Gmail**: Open your default mail client with file link attachment.
- **Analyze Disk Usage**: See total storage used by a directory.
- **Themes**: Switch between color schemes and customize UI colors.
- **Clipboard Integration**: Cut, copy, and paste file paths easily.
